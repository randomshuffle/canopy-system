# Local extrapolations to N=2^30

Projected commitment and opening costs from measured local N=2^22 stages using linear and FFT work models for five WHIR/Bolt configurations and multiple eta values. It records assumptions, scale factors, and provenance.

Original location: `results/n30_prover_time_estimates/`. Forecasts rather than N=2^30 timing measurements; the final extension includes measured AWS data.

The retained logs, manifests, commands, and source bundles describe the original run; historical paths and source hashes have not been rewritten. See [final results and reproduction guidance](../../../results/README.md) for the current experiments.
